# 多智能体课程教学设计平台今日开发记录

> 日期：2026-08-02  
> 版本：v2.0 教师优先工作台  
> 状态：已完成开发、回归与浏览器验收

## 1. 今日目标

今日围绕教师备课主流程完成以下工作：

1. 将长单页改造为“材料预览、生成过程、教学成果”三个工作页。
2. 修正多轮迭代语义，使各轮持续打磨同一批知识点，而不是顺延讲授新章节。
3. 增强 PDF、DOCX、PPTX 材料解析质量，并把解析依据和风险反馈给教师。
4. 提升生成过程可观测性，明确当前智能体、任务、步骤、耗时、Token、响应速度和连接状态。
5. 建立教师成果工作区，支持分块预览、编辑、局部生成、版本恢复、审核、复制和导出。
6. 以真实课本和桌面/平板/手机浏览器逐步验证，发现问题后修复再进入下一环节。

## 2. 用户需求边界

本轮优先服务教师备课、教学设计和资料生产。按已确认范围，以下功能不纳入当前版本：

- 学生先作答、两级提示、答案解析和作答过程记录。
- 按时间显示教师话术、学生任务、预期回答和备用活动的课堂操作模式。
- 收集学生作答、形成班级共性误区并回流下一轮备课。

平台中的“分层学生”是用于检验教学设计覆盖度的智能体角色，不是学生端学习产品。

## 4. 关键实现记录

### 4.1 教师成果工作区

- 新增教师稿持久化和版本历史，保存采用 `base_version` 乐观并发控制。
- 智能体原稿按 Markdown 二级标题拆为资料块，教师可逐块预览或编辑。
- “生成当前资料”只重写当前资料块，不影响其他已确认内容。
- 未保存内容写入浏览器本地存储；再次进入同一会话时自动恢复。
- “保存教师稿”创建新版本；“标记已审核”将当前版本设为教师确认稿。
- 教师版导出优先使用最近保存稿；学生版保持独立精简输出。

### 4.2 教学范围与迭代

- 教师在生成前必须至少选中一个知识点。
- 课时支持 10–180 分钟、5 分钟步进；讲解深度支持概览、标准、深入。
- 范围、课时和深度进入内容分析、教学设计、讲授和督导提示词。
- 下一轮不更换知识范围，而是先使用上一轮督导意见重做教学设计。
- 督导结果凝练为可复用优化提示词，便于后续追加轮次或迁移到其他教学设计。

### 4.3 文档解析

- PDF 使用 PyMuPDF 的坐标、字号和阅读顺序，过滤重复页眉页脚、页码、代码误标题和部分 OCR 噪声。
- DOCX 使用段落样式恢复 Heading 层级，保留段落/表格顺序，并提取文本框、脚注和尾注。
- PPTX 保留幻灯片顺序、项目符号层级、表格、图表系列和演讲者备注。
- 统一输出解析质量报告；中低质量材料不会再误报为“100 分、结构可靠”。

### 4.4 页面与交互

- 顶部三个工作页分别承载原文、过程和成果，减少单页堆叠。
- 生成过程保持六阶段总览；“局部查看”支持教学准备、各轮和完整记录。
- 项目面板和课程洞察默认收起，可独立打开；桌面支持单栏、双栏、三栏。
- 920px 以下洞察移到正文下方；680px 以下项目、正文、洞察纵向排列。
- 消息、分析、设计、练习、评价、提示词和代码块均提供复制按钮。
- 运行日志过滤重复心跳，仅保留节点开始、完成和降级等关键记录。

## 5. 实测问题与修复

| 环节 | 发现的问题 | 修复结果 |
| --- | --- | --- |
| 长教材导入 | 左侧表单下部被会话列表遮挡，无法点击启动 | 表单改为独立纵向滚动区，启动按钮可正常命中 |
| 新材料上传 | 中间和右侧仍显示旧会话内容 | 上传成功后退出旧会话，切换到新材料预览 |
| 范围清空 | 启动按钮仍可点击 | 与课程标题和选中知识点状态联动禁用 |
| 多轮生成 | 下一轮看起来像继续讲新知识 | 固定知识范围，每轮先重做教学设计 |
| 生成等待 | 用户无法判断卡住还是处理中 | 增加步骤、负责人、耗时、心跳和模型指标 |

| OCR 教材 | 乱码和代码片段被误识别为标题 | 加入字号、结构、字符比例、语句特征和页边距过滤 |

## 6. 真实材料验证

测试材料：`book/python程序设计基础与应用(OCR)课本2.pdf`

- 文件大小约 9.3 MB，共 20 页。
- 浏览器上传接口耗时约 0.6 秒。
- 提取 20,268 个处理字符和 24 个有效章节分区。
- 解析质量为 77 分，标记“建议复核”。
- 报告识别到 268 个文本块、20 张图片、0 个疑似扫描页。
- 提示约 19% 文本行可能含 OCR 噪声。
- 章节从“第2章 内置对象、运算符、表达式、关键字”连续到“本章小结”。
- 未再出现“回回”“卜盘、”等历史乱码标题。
- 可打开末章、展开质量详情、滚动设置区并命中启动按钮。

## 8. 当前已知限制

- 旧二进制 `.ppt` 不直接解析，应先另存为 `.pptx`。
- 图片型 PDF 当前只提示疑似扫描页，未内置 OCR 引擎；需要先做 OCR 或提供可搜索 PDF。
- SmartArt、复杂公式、图中标注和依赖版式关系的信息仍需教师结合原文件复核。
- 模型提供方不返回 usage 时，Token 会明确标记为估算值。
- 正式模型的耗时和质量受接口速度、上下文长度及服务配额影响。
