### 真实模型（MiniMax-M3）1 轮实测
- 耗时 141 秒；输出质量优秀：内容剖析贴课本、讲授含代码示例与认知冲突（8.4-0.1==8.3）、分层答疑（基础/进阶/拓展三表）、督导点评专业（含 / // % ** 易错点、-7//2=-4、2**3**2=512 等下一轮重点）。
- 结论：候选知识点锚定对真实模型同样有效；1 轮 141s / 2 轮约 5 分钟，前端等待体验需在环节 3 检查。
