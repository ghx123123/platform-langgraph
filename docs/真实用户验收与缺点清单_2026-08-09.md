### 开源解析方案实测

| 方案 | 真实 DOCX 结果 | 真实 PPTX 结果 | 结论 |
| --- | --- | --- | --- |
| 现有内置解析 | 6,134 字，结构稳定但漏掉图片文字 | 14,896 字，105/105 页和页面顺序可靠 | 保留为结构基线与回退 |
| [Docling 2.109.0](https://github.com/docling-project/docling)（MIT） | 7,167 字，约 5.53 秒 | 16,601 字，约 2.8 秒 | 能增强通用转换，但当前材料收益不足以抵消依赖与复杂度 |

| [CnOCR](https://github.com/breezedeus/CnOCR) + OpenXML 图片关系 | Word 图片补充约 10,086 字，23/26 张有有效文字 | 未对 PPTX 全量图片执行 OCR | 与 MarkItDown 组合落地，图片结果插回原内容位置 |

## 三、发现并已修复的问题

| 级别 | 问题 | 修复与回归结果 |
| --- | --- | --- |
| 高 | 暂停的历史会话继续累计离线时间，出现数千分钟耗时和错误剩余时间 | 暂停后以 `updated_at` 冻结计时；移除不可靠的剩余时间外推 |
| 高 | 第二次督导评价解析到较小 JSON 对象，静默回退为固定 75 分 | JSON 解析改取最大有效对象，缩短评价证据并校验必需字段；真实 PPTX 流程返回 87 分 |
| 高 | 教师稿 PDF 遇到高表格行触发 ReportLab `LayoutError` | 表格允许行内拆分，取消不合理整体包裹；PDF/Markdown 浏览器下载均通过 |
| 高 | PPTX 同名标题被去重，105 页只形成 8 个分区 | PPTX 改为按幻灯片边界保留，真实材料验证为 105/105 分区 |
| 高 | MarkItDown 0.1.x 仅输出 `base64...` 图片占位符，初版界面显示 CnOCR 引擎但实际图片 OCR 为 0 | 改从 DOCX OpenXML 关系按正文顺序读取原图；真实 Word 提升到 17,925 字并识别 23 张图片，新增占位符回归测试 |
| 中 | PPTX 候选知识点按页重复，教师要逐项辨别相同标题 | 同名知识点合并为页码范围，如“7.1.1 机器学习的发展（幻灯片 6-14）”，逐页预览不受影响 |
| 中 | 完整 OCR 的 PDF 被评为 95/结构可靠 | 增加 OCR 保真度扣分；真实扫描 PDF 调整为 79/建议复核 |
| 中 | 图片密集 PPTX 被评为 100/结构可靠 | 增加图片密度、低文本页和章节名冲突提示；真实课件调整为 84/建议复核 |
| 中 | 图片密集 DOCX 被评为 100，且缺少页数元数据时前端显示为 1 页 | 图片密集材料降为 84/建议复核；无页数元数据时显示“页数未知”，不再虚构页数 |
| 中 | 上传耗时较长时仅显示“正在解析”，用户无法判断阶段 | 增加文件名、已用时间及读取/上传/提取/OCR 深度解析阶段文案 |
| 中 | 编号和项目符号知识点重复，且 24 字标题限制误删有效标题 | 调整规范化和去重顺序，放宽标题提取并补充回归测试 |
| 中 | 前端用 `window.open` 导出，失败时没有界面反馈 | 改为 fetch/blob 下载，错误进入统一可见提示 |
| 中 | 只能查看提取文本，教师无法核对原文版式 | 持久化原文件并增加原页接口；PDF 直接预览，DOCX/PPTX 转缓存 PDF，前端提供“原页/提取文本”切换 |
| 中 | 切换教学会话会改变左侧栏状态，且文字按钮占用工作区 | 侧栏仅由页面左侧图标控制；实测连续切换会话后仍保持展开，手动收起/展开正常 |
| 低 | 上传新文件后沿用上一个文件的目录搜索词，出现“0 个分区”假象 | 文件变化时清空目录搜索并复位到首个分区 |
| 低 | 105 页 PPT 原页切换时 PDF 插件短暂空白 | 保留按页重载以确保页码正确，并在大文件渲染期间显示“正在定位原页” |

## 四、仍存在的真实限制

| 级别 | 限制 | 用户影响 | 建议 |
| --- | --- | --- | --- |
| 中 | DOCX 图片已做 OCR，但不能可靠还原公式、流程连线、图表空间关系和复杂视觉语义 | OCR 文本可进入教学设计，但图示关系仍可能被线性化或误识别 | 保留原页对照和风险提示；后续可选接入多模态视觉模型 |
| 中 | 自动候选知识点最多 12 项 | 105 页长课件后半章知识点不会自动进入候选区，需从目录查看后手动添加 | 增加“按章节展开选择”，候选项按一级章节分组并按需加载 |
| 中 | 旧版二进制 `.ppt` 不支持直接解析 | 教师需先另存为 `.pptx` | 前端提示中增加“请用 PowerPoint 另存为 PPTX”；可选接入 LibreOffice 服务端转换 |
| 中 | PPTX 中图片型页面仍有 34 页少于 30 个可访问字符 | 目录存在，但页面视觉内容可能未进入教学设计 | 保留当前风险提示，并在图片 OCR 完成前要求教师抽查这些页 |
| 低 | 移动端三列使用横向滚动，首屏只能看到教师和部分学生列 | 督导列需横向滑动后查看 | 增加教师/学生/督导分段切换，同时保留横向全局模式 |
| 低 | Python 3.12 下 SQLite 默认日期适配器出现弃用警告 | 当前不影响运行，未来 Python 版本可能需要适配 | 显式注册日期时间适配器和转换器 |
