# 多智能体课程教学设计平台用户使用手册

> 适用版本：v2.0 教师优先工作台  
> 更新日期：2026-08-11  
> 主要用户：任课教师、课程负责人、教学设计人员、平台管理员

## 1. 平台定位

平台用于辅助教师读取课程材料、限定教学范围、生成并反复打磨教学设计，以及整理可编辑、可审核、可导出的教师资料。

标准流程如下：

```text
数据中台 → 选择学期和课程 → 按本地目录检索或更新资料
→ 资料整理 → 核对原文件与提取正文 → 选择章节、讲次、主材料和配套材料
→ 课程设计 → 检查解析质量与目录 → 选择知识点/课时/深度
→ 内容剖析 → 教学设计 → 教师讲授 → 分层学生提问
→ 教师答疑 → 督导评价 → 按同一范围进入下一轮打磨
→ 成果编排 → 引用学生问题/思政元素等内容块 → 预览编辑 → 多格式导出
```

多轮迭代的含义是“重复优化同一批指定知识点”，不是自动顺延到下一章节。

## 2. 当前功能

### 2.1 材料处理

- 支持 PDF、DOCX、PPTX、Markdown、TXT。
- “单文档创建教学设计”入口单文件最大 30 MB；数据中台初始导入只建索引，不上传原件，因此不受 80 MB 多文件批次或 360 MB 单文件上传限制。教师确认本讲次材料后，实际按需导入仍会执行上传安全限制。
- 自动识别课程名称、候选知识点、重点知识点和章节分区。
- 显示解析质量、解析引擎、页数、标题/表格/图片/文本块数量、疑似扫描页和风险提示。
- 支持目录搜索、逐区原文阅读、复制当前分区和复制全文。
- 数据中台以课程“主目录”为起点，原始文件、上传文件夹和自建文件夹位于同一棵目录树。支持在当前位置上传文件/文件夹、新建子文件夹、移动、重命名、单项/批量删除；新建时可预览完整落点，文件夹卡片上的删除图标可递归删除其中的平台副本与子目录。提取正文和生成成果不在中台目录中展示。
- 数据中台采用渐进加载：先显示学期和课程，再按需读取所选课程的完整文件目录。左侧不生成章节范围；中间“主目录”按照导入或关联的本地路径层级显示全部文件。目录栏的“已载入 X/Y 份”用于确认整门课程是否加载完整，文件自身的章节元数据仅在后续资料分析和教学设计阶段使用。
- 左侧课程目录按照“学期 → 课程 → 主目录 → 文件夹”展开；点击文件夹会同步中间面包屑，文件夹左侧箭头仅控制子目录展开。学期行右侧铅笔用于重命名学期目录，并同步更新其中全部课程；课程下“主目录”右侧的新建图标用于直接创建课程根文件夹。
- 切换课程时只加载目标课程的完整目录；加载期间课程树保持可操作，目录主区显示当前处理状态。搜索覆盖当前课程的全部资料，不再只显示前 100 条。
- 同一课程可建立多个一级来源根。课程主目录统一提供“导入文件”“导入文件夹”“关联本地路径”；来源卡片显示“浏览器索引”或“本地关联”，并提供刷新、系统打开（仅本地关联）和从平台移除操作。
- 目录文件可切换“类别”或“日期”排序。单击文件名会交给操作系统默认程序打开；本地关联文件的更多菜单提供“重新加载”，用于文件在本机修改后只更新该文件的平台副本。
- 移除来源文件夹只需在确认框点击“确认从平台移除”，无需输入“删除”。该操作只删除平台记录、目录引用和平台托管副本，绝不删除本机源文件或源文件夹。
- 课程目录右侧的垃圾桶用于删除整个课程资料库。平台会先统计将受影响的课程资料、文件副本、教学设计、教学资料包和关联会话；输入“删除”后才可执行。本机源目录不会被删除。该操作不同于删除普通文件夹，且不可撤销。
- 数据中台和资料整理页均支持当前页面内原页预览；可预览的 Word/PPT 会先转换为 PDF，原始 PDF 直接展示。

### 2.2 教学设计

- 编辑、增删候选知识点，设置是否为重点。
- 多选本次教学范围，支持全选、只选重点和清空。
- 设置 10–180 分钟预计课时。
- 设置概览、标准、深入三档讲解深度。
- 设置 1–3 轮教学迭代。
- 可选“教学设计后暂停”和“学生提问后暂停”，允许教师补充意见。

### 2.3 生成与观察

- 六阶段全局流程：内容剖析、教学设计、教师讲授、学生提问、教师答疑、督导点评。
- 显示当前智能体、当前任务、总步骤、任务耗时、后端心跳和最后更新时间。
- 显示上次模型响应时间、Token 和输出速度；无法取得真实 usage 时标记为估算。
- 支持查看教学准备、各轮内容或完整记录。
- 课程洞察包含重难点、教学环节和督导评价。

### 2.4 教师成果

- 按资料块查看成果概览、内容剖析、教学方案、督导评价和课堂记录。
- 支持预览和 Markdown 编辑。
- 对当前资料块填写修改要求并单独重新生成。
- 自动保存本机未提交编辑，重新进入同一会话时恢复。
- 保存教师稿、标记已审核、查看版本历史和恢复旧版本。
- 复制完整教师稿，导出教师版或学生版 Markdown/PDF。

## 3. 使用前准备

### 3.1 启动平台

在项目根目录双击 `run.bat`，或在 PowerShell 中分别运行：

```powershell
python -m uvicorn backend.app:app --host 127.0.0.1 --port 8000
npm --prefix frontend run dev
```

浏览器打开：`http://127.0.0.1:5173`

如果无法访问：

1. 检查后端健康页 `http://127.0.0.1:8000/health`。
2. 检查命令行是否显示端口被占用。
3. 确认 Python 3.11+、Node.js 20+ 和依赖已经安装。

### 3.2 配置模型

1. 点击右上角齿轮按钮。
2. 选择“本地演示模型”或“OpenAI 兼容接口”。
3. 使用兼容接口时填写接口地址、模型名称和 API Key。
4. 根据需要设置温度和超时时间。
5. 先点击“测试连接”，确认模型名和延迟正常。
6. 点击“保存并应用”。

API Key 仅保存在本机后端。前端读取设置时只返回“是否已配置”，不会返回密钥内容；留空保存会保留已有密钥。

## 4. 学期资料到模板教案（推荐流程）

1. 打开“数据中台”，按学期、课程或关键字查找资料，在课程主目录使用以下入口：
   - **导入文件**：选择一个或多个文件，只登记文件索引，并建立独立一级来源根。
   - **导入文件夹**：选择完整文件夹，只登记目录清单和层级，并以该文件夹建立一级来源根。
   - **关联本地路径**：适合平台与资料位于同一台电脑。填写后端可访问的绝对路径后，平台只扫描清单；以后点击来源卡片的刷新图标即可同步新增、修改和移除项。
   建立索引时不复制原件、不提取正文，进度条显示已登记项数。浏览器来源在当前页面会话中临时保留文件权限；页面重载后，按刷新图标重新选择原文件或原文件夹即可恢复权限。
2. 选择课程后，按本地目录逐层打开文件夹。可先打开文件或预览原页，也可勾选多项后从“已选资料”条批量加入成果编排；点击“资料整理与分析”可继续组装备课包。
3. 在资料整理页勾选本讲次需要引用的教材、课件、进度表、教案或历史资料，并用圆点指定主材料。底部“已选资料”会逐项列出文件名并标明主材料，可逐项移除。
4. 点击“确认资料并进入课程设计”。平台先按需导入本次明确选中的原件并显示进度，再提取正文、建立备课包和持久化课程设计稿；未选资料保持未导入、未提取状态，原文件索引、提取正文及讲次数据均保留来源引用。
5. 在“课程设计”核对材料原页、提取内容和知识范围，设置课时、深度及轮次后启动多智能体设计；后续迭代始终优化当前范围。
6. 生成完成后打开“成果编排”。先按“教学设计、问答、思政元素、原始资料”筛选来源，勾选多项并点击“加入当前成果”，再编辑标题、正文与顺序。
7. 切换“预览”检查最终阅读结构，或打开独立打印预览；来源和导入文件可通过眼睛按钮在当前页面核对原页。
8. 保存版本后点击“导出可编辑 Word (.docx)”。Markdown 和中台 JSON 位于“中台交换格式”；JSON 可再次导入，实现跨课程、跨学期复用。

“教案字段编辑”保留结构化目标、重难点、教学过程及 DOCX 模板填充能力；成果编排负责更灵活的跨来源资料组合，两者不互相覆盖。

文件输出支持三种填充方式：模板中的 `{{course_name}}` 等占位符、标签右侧单元格、标签下方合并单元格。模板没有可识别槽位时自动回退为内置标准可编辑教案，并附数据来源。

## 5. 单文档创建教学设计

### 第一步：新建课程

1. 点击左侧“课程设计”区域右上角的加号。
2. 点击“上传课程材料”。
3. 选择 PDF、DOCX、PPTX、Markdown 或 TXT 文件。
4. 等待系统自动切换到“材料预览”。

建议优先上传结构清晰的原文件。平台会自动 OCR 扫描 PDF 和 Word 内的有效尺寸图片；旧 `.ppt` 请先另存为 `.pptx`。公式、流程连线、图表关系和低清图片仍需结合原页复核。

### 第二步：检查解析结果

材料预览页重点检查以下信息：

- **课程名称和文件名**：确认没有读取到旧会话材料。
- **分区数和处理字符数**：判断是否读取到完整正文。
- **解析质量**：展开查看引擎、文本块、页面/图片 OCR 数量和警告。
- **内容目录**：检查章节顺序、层级和标题是否合理。
- **原页**：核对 PDF 原稿或转换后的 Word/PPT 原始版式；PPT 目录可定位到对应幻灯片。
- **提取文本**：检查系统实际送入教学设计的内容，必要时复制当前分区或全文。

质量等级说明：

| 等级 | 含义 | 建议 |
| --- | --- | --- |
| 结构可靠 | 标题和正文结构较稳定 | 抽查重点章节后继续 |
| 建议复核 | 存在 OCR、复杂版式或视觉元素风险 | 检查目录、公式、表格和关键章节 |
| 需要复核 | 文本过少、扫描页较多或噪声明显 | 更换原文件、先做 OCR 或整理后再上传 |

质量分用于提示解析风险，不代表教材内容质量。

### 第三步：确认教学范围

1. 展开“编辑候选知识点”，检查标题、重点标记和重复项。
2. 在“教学范围”中勾选本次要讲的知识点。
3. 可使用“全选”“只选重点”“清空”快速调整。
4. 拖动滑块设置预计课时。
5. 选择讲解深度：
   - 概览：建立知识结构，适合导入或复习。
   - 标准：讲清核心概念并支持基本应用。
   - 深入：聚焦难点、边界条件和知识迁移。
6. 检查课程标题，填写可选的学情、课时或侧重点。
7. 选择 1–3 轮教学迭代。

至少选择一个知识点且课程标题不少于两个字符，启动按钮才会启用。

### 第四步：选择教师介入方式

默认不勾选时，流程自动运行到完成。需要控制过程时可勾选：

- **教学设计后暂停**：查看目标和教学环节，补充重点、案例或时间要求。
- **学生提问后暂停**：查看三类学生问题，补充教师希望回答的角度。

暂停时在输入框填写意见并继续；意见会进入后续节点，而不是只作为备注保存。

### 第五步：启动

点击“启动教学设计”。真实模型一轮通常需要约 2–3 分钟，时间受材料长度、模型服务和网络状态影响。运行中可以点击“停止”。

## 6. 查看生成过程

### 6.1 识别当前阶段

页面顶部六阶段流程用于全局定位：

1. 内容剖析：扫描全文结构、重难点和误区。
2. 教学设计：组织目标、环节、练习和评价。
3. 教师讲授：围绕教师指定范围生成本轮方案。
4. 学生提问：拓展、进阶、基础三类学生智能体并行提问。
5. 教师答疑：分层回应问题并澄清概念边界。
6. 督导点评：评价质量并凝练下一轮优化提示词。

### 6.2 判断是否仍在运行

运行状态区会持续显示：

- 当前负责人和任务。
- 第几步/总步骤和整体进度。
- 当前任务耗时和最后更新时间。
- 后端心跳是否正常。
- 上次模型响应时间、Token 和输出速度。

短时间没有新消息不等于卡住。只要后端心跳正常且最后更新时间持续变化，任务仍在处理。若心跳长时间异常，可刷新页面；运行事件和进度已持久化，不会因为刷新丢失。

### 6.3 全局与局部查看

- 默认正文全宽显示，并只展示最新一轮。
- 点击页面左侧的侧栏图标打开或关闭“课程与会话”；只有该图标会改变侧栏状态，切换会话不会自动收起。
- 使用“局部查看”切换教学准备、各轮和完整记录。
- 点击“课程洞察”打开重难点、教学环节和督导评价。
- 桌面端可以同时打开三栏；手机端会按项目、正文、洞察顺序纵向排列。

### 6.4 复制内容

智能体消息、课程分析、教学设计、学习目标、课堂练习、评价方式、可复用提示词和代码块均可复制。复制成功后按钮会短暂显示“已复制”。

## 7. 多轮打磨

每一轮都使用教师在启动前确定的同一知识范围：

1. 读取上一轮督导评价和可复用优化提示词。
2. 重新组织教学目标与环节。
3. 生成新的讲授方案。
4. 再次由分层学生提问、教师答疑和督导评价。

完成后可在页面底部点击“再跑一轮”，并补充本轮希望优化的教学策略、示例或时间分配。留空时沿用督导提示词。

“再跑一轮”用于继续打磨当前设计，不会自动切换到下一个知识点。

## 8. 核验材料分析覆盖

启动前，材料预览页显示“待分析”。内容剖析完成后再次进入“材料预览”，可看到：

- 全目录分析覆盖率。
- 已检查分区数和深读分区数。
- 教学核心、支撑内容和背景参考数量。
- 每个分区的匹配知识点和分析证据。

这一步用于确认智能体确实扫描整份材料，而不是只读取开头摘要。发现分区归类不合理时，可回到下一轮输入中明确要重点复核的章节。

## 9. 编辑教学成果

教学完成后，“教学成果”页签自动启用。

### 9.1 预览与编辑

1. 在资料目录中选择一个资料块。
2. 使用“预览”检查 Markdown 渲染结果。
3. 切换到“编辑”直接修改文字、标题、表格或代码。
4. 未保存修改会保存在当前浏览器本机；再次进入同一会话时自动恢复。

### 9.2 局部生成

1. 选择需要修改的资料块。
2. 在“本节修改要求”中写明目标，例如：
   - 压缩到 500 字。
   - 补充教材中的公式适用条件。
   - 改为表格，便于教师备课。
   - 保留知识范围，增加一个贴近专业场景的示例。
3. 点击“生成当前资料”。
4. 系统只替换当前资料块，并切换到编辑状态。
5. 检查结果后再保存，不满意可继续修改或重新生成。

### 9.3 保存、审核和恢复

- **保存教师稿**：写入新版本，不覆盖旧版本。
- **标记已审核**：将当前内容设为教师确认稿，后续教师版导出使用该版本。
- **版本历史**：查看版本号、状态和时间。
- **恢复到编辑区**：把旧版本加载为未保存修改；确认后保存会生成新版本，原版本仍保留。

如果多人或多个页面同时编辑同一稿件，版本冲突会阻止覆盖；刷新后基于最新版本继续修改。

### 9.4 导出

- Markdown：适合继续编辑、进入知识库或版本管理。
- PDF：适合预览、打印和分享。
- 教师版：包含教师保存或审核后的完整资料。
- 学生版：使用独立的学生阅读输出，不包含教师工作区状态。

导出前建议先保存并标记已审核，避免下载到未确认的智能体原稿。

## 10. 会话管理

- 左侧“教学会话”显示历史课程、状态、轮次和综合评分。
- 点击会话恢复过程记录、材料覆盖和教学成果。
- 运行中的会话可停止。
- 删除会话前会出现确认操作；删除会同时移除对应事件和教师稿版本，请谨慎执行。

常见状态：

| 状态 | 含义 |
| --- | --- |
| 排队中 | 会话已创建，等待工作流启动 |
| 运行中 | 智能体正在处理 |
| 等待教师 | 在设定的介入点暂停 |
| 已完成 | 所有设定轮次已完成，可编辑成果 |
| 已停止 | 用户主动停止 |
| 失败 | 工作流或模型调用发生错误 |

## 11. 常见问题

| 现象 | 原因判断 | 处理建议 |
| --- | --- | --- |
| 上传后启动按钮不可用 | 未选择知识点或标题过短 | 至少选择一个知识点并检查课程标题 |
| PDF 章节很少或质量低 | 文件是扫描图片或 OCR 较差 | 先做 OCR，优先使用可搜索 PDF |
| PPT 无法上传 | 文件是旧 `.ppt` 格式 | 另存为 `.pptx` 后上传 |
| 图表或 SmartArt 信息不完整 | 视觉关系不能完全转换为文本 | 对照原文件复核并在要求中补充说明 |
| 生成较久没有消息 | 模型正在处理长上下文 | 检查心跳和最后更新时间，不要连续重复启动 |
| Token 显示“约” | 模型服务未返回 usage | 该值为估算，不影响生成结果 |
| 页面显示旧材料 | 仍选中了历史会话 | 新建课程并重新上传；解析成功后会自动退出旧会话 |
| 未保存内容消失 | 更换浏览器、清理站点数据或切换设备 | 重要修改及时点击“保存教师稿” |
| 导出内容不是最新修改 | 本地修改尚未保存 | 保存或标记已审核后重新导出 |
| 原页页签不可用 | 历史索引只有本地路径，没有文档预览地址 | 重新连接原资料目录并扫描，或先查看提取内容 |
| Word 下载后无法识别 | 浏览器下载被代理或旧缓存替换 | 确认文件名以 `.docx` 结尾，刷新页面后从“导出可编辑 Word”重新下载 |
| 模型连接失败 | 地址、模型名、Key、超时或额度异常 | 在设置中重新测试连接并查看接口服务状态 |

## 12. 使用建议

- 一次选择相互关联、可在同一课时完成的知识点，不要一次覆盖整本教材。
- 真实教材出现“建议复核”时，至少抽查目录、公式、表格、代码和关键例题。
- 第一轮先观察结构问题，后续轮次用具体要求修正示例、时间分配和难点解释。
- 局部生成的要求应包含目标、保留项和长度/格式约束，避免只写“优化一下”。
- 教师审核是最终质量门；模型产出不应未经复核直接用于正式课堂。

## 13. 数据与安全

- 会话、事件、检查点和教师稿保存在本机 SQLite 数据库。
- API Key 仅保存在本机后端配置，前端不会读取明文。
- 上传材料会进入模型上下文；使用第三方模型时，应遵守所在单位的数据安全与版权要求。
- 不要上传包含学生个人敏感信息、未授权试题或禁止外传的资料。
- 教师应对课程内容准确性、引用、版权和最终发布负责。

## 14. 当前能力边界

当前版本不提供：

1. 学生先作答、两级提示、答案解析和过程记录。
2. 按分钟执行的课堂操作模式。
3. 学生作答采集、班级误区统计和自动回流备课。

当前平台定位为教师教学设计与资料生产工作台，而不是学生学习平台或课堂行为采集系统。
